# 写作规范（全社团通用）

## 一、三种体裁

| 体裁 | 篇幅 | 要求 |
|------|------|------|
| 历史短文 essay | 400–600 词 | 事件驱动，零公式；至多一个数字；首段 ≤3 句给出 **The practical question:** 开篇；倒数第二段钩住下一篇短文；结尾落到今天读者用的东西 |
| 数学工具 toolkit | 650–800 词 | 一个 A Level 主题 + 1 道完整例题（框内可验算）；框外零公式 |
| 研究长文 feature | 3800–4500 词 | 有贯穿论点；Chicago 脚注；参考文献 ≥18 条；只允许 5 个 boxed example |

## 二、文件命名（交到哪里就按什么命名）

交到 `weeks/week-NN-*/outputs/`：

```
essay-#-角色.md          # 短文，如 essay-1-s1.md
toolkit-b#-角色.md       # 工具栏，如 toolkit-b1-k.md
problem-#-角色.md        # 习题页条目
source-p#-角色.md        # 原典摘译
reading-log-w#-角色.md   # 每周阅读日志（约 150 词）
```

角色代号：`E` 主编、`S1`/`S2` 叙事员、`K` 工具栏作者、`T` 史料员、`N` 解题叙述员、`V` 视觉编辑。
修订后的终稿进 `journal/` 对应目录（essays/toolkits/feature/…）。

## 三、语言

- 刊物正文一律英文。
- `agenda.md`、`notes.md` 等内部文件中英文皆可。

## 四、引用

- 每条史实能指回资料卡编号（见每周计划第五节）。
- 每篇短文 Sources 至少两条：原始记载一条 + 主教材一条。
- 网络一手文献注明 "copy archived at the author's own institutional page"。
- 全文统一 Chicago 脚注。

## 五、红线

- 范文（`journal/essays/sample-*`、`journal/feature/sample-*`）仅供结构与风格参照，投稿稿必须自行写作，不得整段照抄。
- 不用 genius/great man 式形容词；写问题不写崇拜。
- 至少一处「流行说法 vs 原始记载」或「我们不知道什么」的辨析。
- 官方答案类材料（Cipher Challenge 破译报告等）不入库，破译前禁读。
