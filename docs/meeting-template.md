# 标准 90 分钟例会模板（全社团通用）

| 时间 | 活动 | 产出 |
|------|------|------|
| 0–10 分 | 热身：本周数学史一事实 | 可选 |
| 10–35 分 | 主讲：历史事件 + 一图 | 轮换 |
| 35–55 分 | 讨论：「若数学失败会怎样？」 | 每人发言 |
| 55–75 分 | 写作诊所：当场写 150–300 词 | 上传草稿 |
| 75–85 分 | 工具栏或习题（主编/K） | 一道例题 |
| 85–90 分 | 布置作业、提醒截止 | 写进当周 `notes.md` |

- 学期内部分周次的「热身+讨论」段会被微工作坊替换，以该学期 `weekly-plan.md` 第三节为准。
- 会后 5 分钟：把下周阅读条目与勾选状态写进当周 `notes.md`。
