- 流程（10 分钟讲规则）：一条 crib 约束能排除哪些格？轮流上黑板涂掉；每加一条约束（转子顺序固定、反射器、字母不映射自身）再排除一批。
- 收束（5 分钟）：数一数从 26³ ≈ 17576 被压到多少——理解「bombe 是机械化排除器，不是计算机」，这正是要纠正的流行误解。

### 3.4 第 10 周微工作坊：DH 数字握手（20 分钟，替换工具栏段并前移）
- 材料：公开参数 g=5、素数 p=23 写在白板上；每人纸笔。
- 步骤（用下面这组数，已验算）：
  1. Alice 选私密 a=6，算 A=5⁶ mod 23 = 8，公开；
  2. Bob 选私密 b=15，算 B=5¹⁵ mod 23 = 19，公开；
  3. 中间人（主编扮演）能听到 8 和 19，但算不出共同秘密；
  4. Alice 算 19⁶ mod 23 = 2；Bob 算 8¹⁵ mod 23 = 2 —— 相同！共同密钥 = 2。
- 收束：为什么「从 5ⁿ mod 23 反推 n」难？小数字可穷举，2048 位不行 → 引出「困难问题」一词，接 B4。
- 重复平方建议 K 会前练熟，现场演示 5⁶ mod 23 的手算路径。

## 四、Toolkit（工具栏 B1–B4）制作手册

### 4.0 统一结构（每篇 650–800 词，K 起草、主编核数学）
1. **历史钩子**（≤100 词）：从本周讲过的事件切入，不复述短文。
2. **核心记号**：本卷统一用 a ≡ b (mod n)，K 在第 3 周前定稿记号卡贴共享文件夹。
3. **讲清一个方法**：公式 + 直觉，A Level 可接受（Further Math 内容标 ★选读）。
4. **一道 worked example**：分步演算（下面已给，可直接用或替换）。
5. **一道变式练习**：交给 N，进习题页，配「历史钩子」短文。
6. **现代应用段**（≤120 词）：一句制度/工程落地。
7. **课标标注**：在页脚注明对应 AS/Further 考点，便于申请文书引用。

### 4.1 B1「凯撒与频率攻击」（第 3 周草稿，第 6 周定稿）
- 内容：把字母表编号 0–25；加密 E(x) ≡ x + k (mod 26)，解密 D(x) ≡ x − k (mod 26)；穷举攻击 = 25 把钥匙；频率攻击 = 利用自然语言统计规律。
- Worked example（可直接用）：明文 MATH → 编号 12, 0, 19, 7 → +3 → 15, 3, 22, 10 → **PDWK**。
- 反例讨论（给短文 #2 供弹药）：为什么 20 个字母的密文数频率常常失败？——样本太小，理论频率是「长期」现象，接后续概率卷的大数定律伏笔。
- 配图：V 画「密钥空间增长」条形图：凯撒 25 → 替换密码 25! ≈ 1.55×10²⁵ → 恩尼格玛 10²⁰。
- 课标：AS Pure 数列/模运算直觉；AS Statistics 频率。

### 4.2 B2「中国剩余定理」（第 5 周草稿，第 7 周定稿）
- 内容：解同余方程组的手算方法；「时钟算术」直觉。
- Worked example（《孙子算经》原题，已验算）：x ≡ 2 (mod 3)，x ≡ 3 (mod 5)，x ≡ 2 (mod 7)。
  - 逐步：M=105；对 3：M₁=35，找 35y≡1 (mod 3) → y≡2；对 5：M₂=21≡1 (mod 5) → y=1；对 7：M₃=15，15≡1 (mod 7) → y=1。
  - x = 2·35·2 + 3·21·1 + 2·15·1 = 140 + 63 + 30 = 233 ≡ **23 (mod 105)**。验算：23÷3 余 2 ✓；23÷5 余 3 ✓；23÷7 余 2 ✓。
- 变式练习（给 N）：x ≡ 3 (mod 5)，x ≡ 1 (mod 7)——最小正整数解 8。
- 注意：三种讲法（逐步试探/口诀「三人七十稀」/构造法）选构造法为主线，口诀只作史料点缀，避免刊物变成奥数讲义。
- 课标：AS Pure 序列与整除；★选读：为什么 CRT 让并行计算变快。

### 4.3 B3「模幂运算」（第 8 周草稿，第 9 周定稿）
- 内容：重复平方（square-and-multiply）；为什么 RSA 能快。
- Worked example 1：3¹³ mod 7 → 3²≡2，3⁴≡4，3⁸≡2；13=8+4+1 → 2·4·3=24 ≡ **3 (mod 7)**。
- Worked example 2（RSA 玩具版，已验算）：p=3, q=11 → n=33, φ=20, 取 e=3, d=7；加密 m=7：c=7³ mod 33=343−330=**13**；解密：13⁷ mod 33 → 13²≡4, 13⁴≡16, 13⁷≡16·4·13=832−825=**7** ✓ 回到明文。
- 变式练习（给 N）：2¹⁰ mod 11 = **1**（1024−1023）；追问「为什么刚好是 1？」留给 Feature §5。
- 配图：V 画「指数按二进制拆」的流水线小图。
- 课标：AS Pure 指数法则；Further 数论入门。

### 4.4 B4「HTTPS 概念」（第 10 周草稿，第 12 周定稿）
- 定位：不要求证明，讲「协议分工」：DH/RSA 协商会话密钥（非对称，慢）→ AES 加密内容（对称，快）→ 证书链证明「这是银行不是骗子」（信任）。
- 必做素材：第 3.4 节握手演示的数字直接作例题；画一张三方时序图（Alice / Bob / 中间人），V 负责。
- 现代应用段：网银锁头标志、TLS 1.3 的 1-RTT（引用一句 RFC 8446 即可，☆ 需工具）。
- 课标衔接：本条最贴帝国理工面试题「解释你的浏览器为什么信这把锁」，全员面试准备素材。
